# 連銀総裁クイズ

米国12地区の連邦準備銀行(連銀)の名前を見て、総裁の名前を答える一問一答クイズです。
答えると、総裁の名前と一緒にタカ派・ハト派・中立の分類が表示されます。

公開ページ: https://chanhase.github.io/fed-presidents-quiz/

## 遊び方

- 連銀名が表示されたら、総裁の姓を入力して「答える」(カタカナ・英語どちらでも可)
- 分からなければ「わからない」で答えを表示
- 最後まで解くと、間違えた問題だけをやり直せます

## データ

- 総裁の顔ぶれ:2026年11月時点(アトランタ連銀は暫定総裁)
- タカ派・ハト派・中立:2026年の発言や投票行動の報道をもとにした大まかな目安

総裁が交代したら `index.html` の `DATA` 配列を書き換えてください。
